# 003 welcome

Welcome to Corbels FTC Programming Lessons in Java! It teaches you to program an FTC robot in Java,
one page at a time.

:::{figure} ../_static/figures/fig-robot-front.png
:name: fig-robot-front
:::

This guide explains how to program FTC robots, one lesson at a time. Each lesson page says
what you will have when it is done, what has to be true before you start, and the steps to get
there. Every step tells you what you will see when it worked.

**How to use it.**

- **It's best to start at the beginning.** But you don't have to, other than getting the wheel
  directions right in lesson L050, Pinpoint installed in lesson L115, and Pedro Pathing tuned in
  lesson L117. Most can be accomplished without doing
  the previous lesson.
- **Do the step, then read the check.** The check tells you whether to go on.
- **The answers are in the back.** Use them when you have tried and need a hint.
- The code and the source to build these pages are at
  <https://github.com/msb-stitt/ftc31459-26-27-biobuzz>.
- Versions of this book are listed at <https://msb-stitt.github.io/ftc31459-26-27-biobuzz/>.
