# What the student writes

Every lesson's copies and patches, from applying `solutions/` on `solutions-try` in
order. Each page is one lesson, each section one file, and each diff is one edit
a student makes, comments included.

The edits are grouped by where the two sides of a patch differ, not by the TODO
numbering, so a run holding three markers is one edit and is named after all three.
