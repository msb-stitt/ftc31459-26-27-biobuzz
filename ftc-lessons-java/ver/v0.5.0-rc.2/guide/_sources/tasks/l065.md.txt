## the steps

In L060 you wrote `deadband` and `signedSquared` inside the OpMode. Here you move them into a
**class** of their own, `StickShaper`. A class is a kind of thing. An **object** is one thing made
from a class. The OpMode makes one `StickShaper` object and asks it for each shaped speed.

### L065S030: the class and what it holds

`StickShaper`'s starter holds only a comment. You type the rest.

A **field** is a variable that belongs to an object. It keeps its value for as long as the object
lives. A `StickShaper` has two fields: `band`, the deadband, and `shape`, how it shapes.

An **`enum`** is a short list of names, and a variable of its kind holds one of them. `Shape` has
three: `LINEAR` leaves the speed as it is, `SQUARED` squares it, as L060 did, and `CUBED` cubes it.

A **constructor** is the code that runs when an object is made. It has the class's name and no
return type. This one takes the band, and puts it in the field `band`. `shape` starts as `SQUARED`.

Later lessons use `StickShaper` from outside the `l065` package. So the class, its `enum`, its
constructor and the methods they call are `public`.

**Change.** In `StickShaper`, type the `package` line above the comment:

```{code-block} java
:caption: mytry/l065/StickShaper.java
package org.firstinspires.ftc.teamcode.mytry.l065;
```

Below the comment, type:

```{code-block} java
:caption: mytry/l065/StickShaper.java
// 'public' so later lessons, in other packages, can use it. 'public' allows access from any code.
public class StickShaper {

    // 'public' so later lessons, in other packages, can use it. 'public' allows access from any code.
    public enum Shape {
        LINEAR,
        SQUARED,
        CUBED
    }

    double band;
    Shape shape = Shape.SQUARED;

    // 'public' so later lessons, in other packages, can use it. 'public' allows access from any code.
    public StickShaper(double bandToSetToZero) {
        band = bandToSetToZero;
    }
}
```

**Build.** In the Terminal, run:

```
./gradlew :TeamCode:compileDebugJavaWithJavac
```

**Check.**

- The Terminal ends with `BUILD SUCCESSFUL`.

### L065S040: the three shapes

**Change.** In `StickShaper`, under the constructor and above the last `}`, type the three methods
that shape a speed. `deadband` and `signedSquared` are the ones you wrote in L060, so you can copy
them from `L060ShapingOpMode`. `cubed` is new.

```{code-block} java
:caption: mytry/l065/StickShaper.java
    double deadband(double value, double band) {
        double alwaysPositiveMagnitude = Math.abs(value);
        boolean isCloseToZero = alwaysPositiveMagnitude < band;
        if (isCloseToZero) {
            return 0.0;
        }
        return value;
    }

    double signedSquared(double value) {
        double alwaysPositiveValue = Math.abs(value);
        double valueSquaredKeepingTheSign = value * alwaysPositiveValue;
        return valueSquaredKeepingTheSign;
    }

    double cubed(double value) {
        double valueCubed = value * value * value;
        return valueCubed;
    }
```

Cubing keeps the sign with no `Math.abs`. A minus times a minus times a minus is a minus:

- `+0.5 * +0.5 * +0.5` is `+0.125`
- `-0.5 * -0.5 * -0.5` is `-0.125`

**Build.** Run the same command again.

**Check.**

- The Terminal ends with `BUILD SUCCESSFUL`.

### L065S050: shape a speed

**Change.** Under the constructor, above `deadband`, type:

```{code-block} java
:caption: mytry/l065/StickShaper.java
    // 'public' so later lessons, in other packages, can use it. 'public' allows access from any code.
    public void setBand(double bandToSetToZero) {
        band = bandToSetToZero;
    }

    // 'public' so later lessons, in other packages, can use it. 'public' allows access from any code.
    public void setShape(Shape newShape) {
        shape = newShape;
    }

    // 'public' so later lessons, in other packages, can use it. 'public' allows access from any code.
    public double shaped(double value) {
        double outsideTheBand = deadband(value, band);
        double shapedValue = outsideTheBand;
        switch (shape) {
            case LINEAR:
                break;
            case SQUARED:
                shapedValue = signedSquared(outsideTheBand);
                break;
            case CUBED:
                shapedValue = cubed(outsideTheBand);
                break;
        }
        return shapedValue;
    }
```

`setBand` and `setShape` change the fields. `shaped` does the work: the deadband first, then the
shape the object holds.

`shaped` hands its parameter `value` on to `deadband`, with the field `band`. Then it hands what
comes back, `outsideTheBand`, on to `signedSquared` or `cubed`. A method can pass its own
parameters on to another method.

A **`switch`** runs the lines under the `case` that matches. `break` ends the `switch`. For
`LINEAR`, nothing runs, so `shapedValue` stays the speed after the deadband.

**Build.** Run the same command again.

**Check.**

- The Terminal ends with `BUILD SUCCESSFUL`.

### L065S070: ask it for each speed

**Change.** In `driveFromTheSticks()`, under the comment that names this step, type:

```{code-block} java
:caption: mytry/l065/L065ShaperOpMode.java
        double leftShapedSpeed = stickShaper.shaped(leftSpeed);
        Tracker.publish("drivetrain/leftShapedSpeed", leftShapedSpeed);
        double rightShapedSpeed = stickShaper.shaped(rightSpeed);
        Tracker.publish("drivetrain/rightShapedSpeed", rightShapedSpeed);
```

Then change the four `setPower` lines below, so each one gets the shaped speed:

```{code-block} java
:caption: mytry/l065/L065ShaperOpMode.java
        hardware.frontLeft.setPower(leftShapedSpeed);
        hardware.backLeft.setPower(leftShapedSpeed);

        hardware.frontRight.setPower(rightShapedSpeed);
        hardware.backRight.setPower(rightShapedSpeed);
```

`driveFromTheSticks()` does not know the band or the shape. It asks `stickShaper`, and gets a
shaped speed back.

**Simulator.** In the Terminal, run:

```
./gradlew :TeamCode:simRun --args="mytry.l065.L065ShaperOpMode --pad"
```

**AdvantageScope.** Connect to the simulator as in L020. Drag `leftSpeed` and `leftShapedSpeed`
from the `drivetrain` folder into **Left Axis**.

**Check.**

- Let go of the sticks. `drivetrain/leftShapedSpeed` reads 0.0.
- Push the left stick halfway forward. `drivetrain/leftSpeed` reads 0.5, and
  `drivetrain/leftShapedSpeed` reads 0.25.

**No gamepad.** `--args="mytry.l065.L065ShaperOpMode --left_stick_y=-0.5 --right_stick_y=0.5"`
holds the sticks half forward and half back.

**If it didn't**, and `drivetrain/leftShapedSpeed` reads 0.125 in L065S070, a `break` is missing
under `case SQUARED:`. The `switch` runs on into `CUBED`. `LessonsTest.l065_theShaperGivesEachShape`
fails with `squared until told otherwise expected:<0.25> but was:<0.125>`.

**What you just did.** The code that drives asks for a shaped speed and gets one back. It does not
know which shapes exist, or which one is set. Only the code that makes or sets the `StickShaper`
knows that. So a new shape, or a menu that picks one, changes `StickShaper` and the code that sets
it, and nothing that drives.
