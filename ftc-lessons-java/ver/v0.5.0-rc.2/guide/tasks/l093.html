093 lesson: write a menu, test first¶

After INIT, the Driver Station shows a menu. The driver picks from each row with the gamepad’s D-pad and its A and B buttons, before pressing PLAY.

the menu, press by press¶

The menu you try here has three rows. Light is On or Off, Speed is Slow, Medium or Fast, and Color is Red, Green or Blue. L095 and L135 use the same menu, with rows of their own.

The top line is the status line. It holds the short name of the choice selected in each row, joined by -. ON-S-R is On, Slow and Red. It changes only when A selects a choice.

  • The > marks the row the D-pad is on.

  • Right and left offer the next or the last choice in that row, as Off? A:OK B:Back. Past the end of the row, they go round to the other end.

  • A selects the choice offered.

  • B, up or down clears the offer.

  • Down and up move the >. Past the last row, it goes round to the first.

Each picture is one press, and the screen it leaves. The first is at the top of this page: at INIT, each row starts at its first choice, selected, and the > is on Light.

Right offers Off. The status line still reads ON-S-R: nothing is selected yet.

B clears the offer. On is still selected.

Right offers Off again.

A selects Off. Now the status line reads OFF-S-R.

Down moves the > to Speed.

Left goes back past Slow, the start of the row, round to Fast.

A selects it. The status line reads OFF-F-R.

Down moves the > to Color.

Right offers Green.

Right offers Blue.

A selects Blue. The status line reads OFF-F-B.

Right goes past Blue, the end of the row, round to Red.

Down goes past the last row, round to the first, and clears the offer of Red. Blue stays selected.

Up goes past the first row, round to the last.

the classes¶

Each class does one job. A class with one small job is easy to test, and easy to change. You build them from the bottom up: MenuItem, then MenuRow, which holds MenuItems, then OptionMenu, MenuButtons and DriverStationMenu. For each class, you test it first, then write it. The tests use the rows L135’s auto uses, Alliance and Auto.

The class diagrams are drawn as in E067. Two marks are new.

- in front of a name means private: only the class’s own code can use it. Here only A’s own next() can read or change count:

public class A {
    private int count;

    public int next() {
        count = count + 1;
        return count;
    }
}

A dashed arrow with an open head means uses: the class at the tail is handed the other one and calls it, but does not hold one. No field makes it. Here A is handed a B and calls its go():

public class A {
    void look(B b) {
        b.go();
    }
}

A MenuButtons uses a Gamepad the same way: it is handed one each loop and asks it about its buttons.

MenuItem: one choice¶

A MenuItem’s one job is to hold a choice’s two names.

  • shortName holds the name for the status line, such as F24.

  • fullName holds the name for the row’s line, such as Forward 24.

  • MenuItem(shortName, fullName) makes a MenuItem from the two names.

  • getShortName() gives back the short name, and getFullName() the full name.

MenuRow: one row of choices¶

A MenuRow’s one job is to know which of its choices is selected, and which is offered.

  • name holds the row’s name, such as Alliance.

  • items holds the row’s MenuItems, in the order they were added.

  • selectedIndex holds which item is selected, and offeredIndex which item the row shows. When the two are the same, nothing is offered.

  • MenuRow(name) makes an empty row, and add(item) puts an item at its end.

  • goRight() and goLeft() offer the next or the last item, round the ends.

  • select() selects the item offered, and goBack() clears the offer.

  • getSelected() gives back the item selected.

  • getLine() gives back the row’s line, such as Alliance: <Red> or Alliance: Blue? A:OK B:Back.

L093S040: one row, and its line¶

An ArrayList holds a list of objects, and grows as you add to them. ArrayList<MenuItem> is a list of MenuItems. It starts empty. add(item) puts item at its end, get(i) gives back the item at i, counting from 0, and size() is how many it holds. import java.util.ArrayList; lets the class use it.

// 'public' so later lessons, in other packages, can use it. 'public' allows access from any code.
public class MenuRow {

    // 'private' so only this class can use it. 'private' allows access from this class only.
    private String name;
    // 'private' so only this class can use it. 'private' allows access from this class only.
    private ArrayList<MenuItem> items = new ArrayList<>();
    // 'private' so only this class can use it. 'private' allows access from this class only.
    private int selectedIndex = 0;
    // 'private' so only this class can use it. 'private' allows access from this class only.
    private int offeredIndex = 0;

    // 'public' so later lessons, in other packages, can use it. 'public' allows access from any code.
    public MenuRow(String name) {
        this.name = name;
    }

    // 'public' so later lessons, in other packages, can use it. 'public' allows access from any code.
    public void add(MenuItem item) {
        items.add(item);
    }

    // 'public' so later lessons, in other packages, can use it. 'public' allows access from any code.
    public MenuItem getSelected() {
        MenuItem selectedItem = items.get(selectedIndex);
        return selectedItem;
    }

    String getLine() {
        MenuItem offeredItem = items.get(offeredIndex);
        String fullName = offeredItem.getFullName();
        String choiceShown = "<" + fullName + ">";
        if (offeredIndex != selectedIndex) {
            choiceShown = fullName + "? A:OK B:Back";
        }
        String rowLine = name + ": " + choiceShown;
        return rowLine;
    }
}

OptionMenu: the rows together¶

An OptionMenu’s one job is to know which row the > is on, and hand each press to that row. The diagram shows MenuRow and MenuItem too, since the calls below reach them. MenuItem is drawn as only its name; its own diagram is above.

  • rows holds the menu’s MenuRows, in the order they were added.

  • pointedIndex holds which row the > is on.

  • add(row) puts a row at the end of the menu.

  • goUp() and goDown() clear the offer in the row the > leaves, then move it, round the ends.

  • goRight(), goLeft(), select() and goBack() hand the press to the row the > is on.

  • getSummary() gives back the status line, such as R-N.

mytry/l093/OptionMenu.java¶
// 'public' so later lessons, in other packages, can use it. 'public' allows access from any code.
public class OptionMenu {

    // 'private' so only this class can use it. 'private' allows access from this class only.
    private ArrayList<MenuRow> rows = new ArrayList<>();
    // 'private' so only this class can use it. 'private' allows access from this class only.
    private int pointedIndex = 0;

    // 'public' so later lessons, in other packages, can use it. 'public' allows access from any code.
    public void add(MenuRow row) {
        rows.add(row);
    }

    String getSummary() {
        String summary = "";
        String between = "";
        for (MenuRow row : rows) {
            MenuItem selectedItem = row.getSelected();
            String shortName = selectedItem.getShortName();
            summary = summary + between + shortName;
            between = "-";
        }
        return summary;
    }

    ArrayList<String> getLines() {
        ArrayList<String> lines = new ArrayList<>();
        String summary = getSummary();
        lines.add(summary);
        MenuRow pointedRow = rows.get(pointedIndex);
        for (MenuRow row : rows) {
            String pointer = "  ";
            if (row == pointedRow) {
                pointer = "> ";
            }
            String rowLine = row.getLine();
            String pointedLine = pointer + rowLine;
            lines.add(pointedLine);
        }
        return lines;
    }
}

between is empty before the first row, and - after it, so - goes only between the names.

mytry/l093/MenuButtons.java¶
class MenuButtons {

    // 'private' so only this class can use it. 'private' allows access from this class only.
    private OptionMenu optionMenu;

    MenuButtons(OptionMenu optionMenu) {
        this.optionMenu = optionMenu;
    }

    void loop(Gamepad gamepad) {
        if (gamepad.dpadUpWasPressed()) {
            optionMenu.goUp();
        }
        if (gamepad.dpadDownWasPressed()) {
            optionMenu.goDown();
        }
        if (gamepad.dpadLeftWasPressed()) {
            optionMenu.goLeft();
        }
        if (gamepad.dpadRightWasPressed()) {
            optionMenu.goRight();
        }
        if (gamepad.aWasPressed()) {
            optionMenu.select();
        }
        if (gamepad.bWasPressed()) {
            optionMenu.goBack();
        }
    }
}

DriverStationMenu: the menu on the Driver Station¶

A DriverStationMenu’s one job is to be the menu an OpMode uses. Each loop, it reads the buttons. Then it shows the lines on the Driver Station.

Tracker shows only the methods DriverStationMenu calls. It uses Tracker and holds none.

L093MenuOpMode shows only menu and init_loop(), which calls loop. You type them in L093S110.

  • optionMenu holds the menu, and menuButtons the MenuButtons it makes for it.

  • DriverStationMenu(optionMenu) makes one for the menu.

  • loop(gamepad) moves the menu for each press, logs the status line as menu/summary, and prints each line on the Driver Station.

  • getSummary() gives back the status line.

One loop(), from the OpMode’s init_loop():

// 'public' so later lessons, in other packages, can use it. 'public' allows access from any code.
public class DriverStationMenu {

    // 'private' so only this class can use it. 'private' allows access from this class only.
    private OptionMenu optionMenu;
    // 'private' so only this class can use it. 'private' allows access from this class only.
    private MenuButtons menuButtons;

    // 'public' so later lessons, in other packages, can use it. 'public' allows access from any code.
    public DriverStationMenu(OptionMenu optionMenu) {
        this.optionMenu = optionMenu;
        menuButtons = new MenuButtons(optionMenu);
    }

    // 'public' so later lessons, in other packages, can use it. 'public' allows access from any code.
    public void loop(Gamepad gamepad) {
        menuButtons.loop(gamepad);
        String summary = optionMenu.getSummary();
        Tracker.publish("menu/summary", summary);
        ArrayList<String> lines = optionMenu.getLines();
        for (String line : lines) {
            Tracker.printToDs(line);
        }
    }

    // 'public' so later lessons, in other packages, can use it. 'public' allows access from any code.
    public String getSummary() {
        String summary = optionMenu.getSummary();
        return summary;
    }
}
