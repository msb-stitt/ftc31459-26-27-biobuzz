### L030S030: the left speed

We are working toward tank drive, where the left stick drives the left wheels and the right
stick drives the right wheels. Push a stick away from you and its wheels should turn forward. We
call forward speeds positive and backward speeds negative. But in L020 a stick pushed away read
-1.0, so its number has to be turned around to make a speed.

The starter already has the four lines you wrote in L020. They read the sticks and write them
down.

**Change.** Under the comment that names this step, type `double leftSpeed = -leftS`. The list
offers `leftStickY`, the name from the lines above. Press Tab, then finish the two lines:

:::{figure} ../_figures/fig-l030-complete.png
:name: fig-l030-complete
:figclass: file-named

fig-l030-complete.png
:::

```{code-block} java
:emphasize-lines: 4-5

        // When on L030S030, see
        // https://coding.stitt.cc/ftc-lessons-java/guide/tasks/l030.html#l030s030
        // for what to do here.
        double leftSpeed = -leftStickY;
        Tracker.publish("drivetrain/leftSpeed", leftSpeed);
```

The minus sign turns the number around: -1.0 becomes 1.0, and 0.5 becomes -0.5. `leftStickY` is
still what the stick says, and `leftSpeed` is how fast the wheels should go. Keeping two names for
the two ideas means each name always says what it holds.

**Simulator.** In the Terminal, run:

```
./gradlew :TeamCode:simRun --args="mytry.L030SpeedsOpMode --pad"
```

**AdvantageScope.** Connect to the simulator as in L020. Type `leftStickY` in the search box.
Drag `leftStickY` from the `gamepad1` folder, and `leftSpeed` from the `drivetrain` folder, into
**Left Axis**.

**Check.**

- Push the left stick away from you. `gamepad1/leftStickY` goes to -1.0, and `drivetrain/leftSpeed`
  goes to 1.0.
- The two lines are always mirror images of each other.

### L030S040: the right speed

**Change.** Press Ctrl+C in the Terminal to stop the simulator. Under the comment that names this
step, do the same for the right stick:

```{code-block} java
:emphasize-lines: 4-5

        // When on L030S040, see
        // https://coding.stitt.cc/ftc-lessons-java/guide/tasks/l030.html#l030s040
        // for what to do here.
        double rightSpeed = -rightStickY;
        Tracker.publish("drivetrain/rightSpeed", rightSpeed);
```

**Simulator.** Run the same command again.

**AdvantageScope.** Drag `rightStickY` from `gamepad1` and `rightSpeed` from `drivetrain` into
**Left Axis**.

**Check.**

- Push both sticks away from you. Both speeds read 1.0.
- Pull both back, and both read -1.0.

**What's happening.** [E035](e035.md) shows why each speed has a minus sign.

::::{only} mentor
**What you just did.** Each speed is its stick with a minus sign in front, so forward is positive
from here on. The stick and the speed have separate names because they are separate things: one
is what the driver's hand does, the other is what the wheels should do. A name like
`leftStick = -gamepad1.left_stick_y` would hide that.

**Where next.** [L040](l040.md) sends `leftSpeed` and `rightSpeed` to the wheels and drives the
robot in the simulator.
::::
