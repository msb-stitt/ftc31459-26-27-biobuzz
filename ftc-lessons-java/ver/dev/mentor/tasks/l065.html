065 lesson: put the shaping in a class¶

The robot drives just as it did in L060. Now one object does all the shaping, and it can shape three ways.

Before you start.

  • L060 is done, so mytry holds L060ShapingOpMode.

  • AdvantageScope is installed on the same laptop, and a gamepad is plugged into the laptop.

  • No robot is needed.

the steps¶

In L060 you wrote deadband and signedSquared inside the OpMode. Here you move them into a class of their own, StickShaper. A class is a kind of thing. An object is one thing made from a class. The OpMode makes one StickShaper object and asks it for each shaped speed.

L065S010: copy the starters into mytry¶

L065’s classes get a folder of their own, l065, inside mytry. The folder is a package. Classes in the same package use each other with no import.

Copy. In lessons, click the l065 folder once and copy it. Click mytry once and paste. If Android Studio asks whether to add the files to Git, click Add.

Check.

  • mytry holds l065, with L065ShaperOpMode and StickShaper.

  • The first line of L065ShaperOpMode reads package org.firstinspires.ftc.teamcode.mytry.l065;.

L065S020: switch your copy on¶

Change. In L065ShaperOpMode, delete the line @Disabled, under the comment that names this step.

Check.

  • Under the step’s comment, the next line reads // 'public' so the robot can run this OpMode. 'public' allows access from any code.

L065S030: the class and what it holds¶

StickShaper’s starter holds only a comment. You type the rest.

A field is a variable that belongs to an object. It keeps its value for as long as the object lives. A StickShaper has two fields: band, the deadband, and shape, how it shapes.

An enum is a short list of names, and a variable of its kind holds one of them. Shape has three: LINEAR leaves the speed as it is, SQUARED squares it, as L060 did, and CUBED cubes it.

A constructor is the code that runs when an object is made. It has the class’s name and no return type. This one takes the band, and puts it in the field band. shape starts as SQUARED.

Later lessons use StickShaper from outside the l065 package. So the class, its enum, its constructor and the methods they call are public.

Change. In StickShaper, type the package line above the comment:

mytry/l065/StickShaper.java¶
package org.firstinspires.ftc.teamcode.mytry.l065;

Below the comment, type:

mytry/l065/StickShaper.java¶
// 'public' so later lessons, in other packages, can use it. 'public' allows access from any code.
public class StickShaper {

    // 'public' so later lessons, in other packages, can use it. 'public' allows access from any code.
    public enum Shape {
        LINEAR,
        SQUARED,
        CUBED
    }

    double band;
    Shape shape = Shape.SQUARED;

    // 'public' so later lessons, in other packages, can use it. 'public' allows access from any code.
    public StickShaper(double bandToSetToZero) {
        band = bandToSetToZero;
    }
}

Build. In the Terminal, run:

./gradlew :TeamCode:compileDebugJavaWithJavac

Check.

  • The Terminal ends with BUILD SUCCESSFUL.

L065S040: the three shapes¶

Change. In StickShaper, under the constructor and above the last }, type the three methods that shape a speed. deadband and signedSquared are the ones you wrote in L060, so you can copy them from L060ShapingOpMode. cubed is new.

mytry/l065/StickShaper.java¶
    double deadband(double value, double band) {
        double alwaysPositiveMagnitude = Math.abs(value);
        boolean isCloseToZero = alwaysPositiveMagnitude < band;
        if (isCloseToZero) {
            return 0.0;
        }
        return value;
    }

    double signedSquared(double value) {
        double alwaysPositiveValue = Math.abs(value);
        double valueSquaredKeepingTheSign = value * alwaysPositiveValue;
        return valueSquaredKeepingTheSign;
    }

    double cubed(double value) {
        double valueCubed = value * value * value;
        return valueCubed;
    }

Cubing keeps the sign with no Math.abs. A minus times a minus times a minus is a minus:

  • +0.5 * +0.5 * +0.5 is +0.125

  • -0.5 * -0.5 * -0.5 is -0.125

Build. Run the same command again.

Check.

  • The Terminal ends with BUILD SUCCESSFUL.

L065S050: shape a speed¶

Change. Under the constructor, above deadband, type:

mytry/l065/StickShaper.java¶
    // 'public' so later lessons, in other packages, can use it. 'public' allows access from any code.
    public void setBand(double bandToSetToZero) {
        band = bandToSetToZero;
    }

    // 'public' so later lessons, in other packages, can use it. 'public' allows access from any code.
    public void setShape(Shape newShape) {
        shape = newShape;
    }

    // 'public' so later lessons, in other packages, can use it. 'public' allows access from any code.
    public double shaped(double value) {
        double outsideTheBand = deadband(value, band);
        double shapedValue = outsideTheBand;
        switch (shape) {
            case LINEAR:
                break;
            case SQUARED:
                shapedValue = signedSquared(outsideTheBand);
                break;
            case CUBED:
                shapedValue = cubed(outsideTheBand);
                break;
        }
        return shapedValue;
    }

setBand and setShape change the fields. shaped does the work: the deadband first, then the shape the object holds.

A switch runs the lines under the case that matches. break ends the switch. For LINEAR, nothing runs, so shapedValue stays the speed after the deadband.

Build. Run the same command again.

Check.

  • The Terminal ends with BUILD SUCCESSFUL.

L065S060: make the object¶

Change. In L065ShaperOpMode, near the top, find the comment that names this step. Under it, type:

mytry/l065/L065ShaperOpMode.java¶
    StickShaper stickShaper = new StickShaper(0.05);

new makes an object. It runs the constructor, with 0.05 as the band. stickShaper is a field of the OpMode, so the same object is used from one loop to the next.

Build. Run the same command again.

Check.

  • The Terminal ends with BUILD SUCCESSFUL.

L065S070: ask it for each speed¶

Change. In driveFromTheSticks(), under the comment that names this step, type:

mytry/l065/L065ShaperOpMode.java¶
        double leftShapedSpeed = stickShaper.shaped(leftSpeed);
        Tracker.publish("drivetrain/leftShapedSpeed", leftShapedSpeed);
        double rightShapedSpeed = stickShaper.shaped(rightSpeed);
        Tracker.publish("drivetrain/rightShapedSpeed", rightShapedSpeed);

Then change the four setPower lines below, so each one gets the shaped speed:

mytry/l065/L065ShaperOpMode.java¶
        hardware.frontLeft.setPower(leftShapedSpeed);
        hardware.backLeft.setPower(leftShapedSpeed);

        hardware.frontRight.setPower(rightShapedSpeed);
        hardware.backRight.setPower(rightShapedSpeed);

driveFromTheSticks() does not know the band or the shape. It asks stickShaper, and gets a shaped speed back.

Simulator. In the Terminal, run:

./gradlew :TeamCode:simRun --args="mytry.l065.L065ShaperOpMode --pad"

AdvantageScope. Connect to the simulator as in L020. Drag leftSpeed and leftShapedSpeed from the drivetrain folder into Left Axis.

Check.

  • Let go of the sticks. drivetrain/leftShapedSpeed reads 0.0.

  • Push the left stick halfway forward. drivetrain/leftSpeed reads 0.5, and drivetrain/leftShapedSpeed reads 0.25.

L065S080: try another shape¶

Change. Press Ctrl+C in the Terminal to stop the simulator. In init(), under the comment that names this step, type stickShaper.setShape(StickShaper.Shape.CUBED);.

Simulator. Run the same command again, and connect AdvantageScope.

Check.

  • Push the left stick halfway forward. drivetrain/leftShapedSpeed reads 0.125.

Only one line changed, and driveFromTheSticks() did not change at all.

Change. Stop the simulator, and delete the line you just typed. Later lessons use the shape a new StickShaper starts with, SQUARED.

What’s happening. E067 draws your class and its calls as UML diagrams.

No gamepad. --args="mytry.l065.L065ShaperOpMode --left_stick_y=-0.5 --right_stick_y=0.5" holds the sticks half forward and half back.

If it didn’t, and drivetrain/leftShapedSpeed reads 0.125 in L065S070, a break is missing under case SQUARED:. The switch runs on into CUBED. LessonsTest.l065_theShaperGivesEachShape fails with squared until told otherwise expected:<0.25> but was:<0.125>.

What you just did. The code that drives asks for a shaped speed and gets one back. It does not know which shapes exist, or which one is set. Only the code that makes or sets the StickShaper knows that. So a new shape, or a menu that picks one, changes StickShaper and the code that sets it, and nothing that drives.

Where next. L070 reads the buttons and the sideways sticks.
