135 lesson: choose the alliance and the auto¶

After INIT, the Driver Station shows a menu. The driver picks Red or Blue, and nothing, L125’s auto or L130’s, with the gamepad’s D-pad, before pressing PLAY.

the problem¶

The menu has two rows. Alliance is Red or Blue, and Auto is Nothing, Forward 24 or Forward Then Strafe. Each row starts at its first choice.

  • The first line is the menu in short: a few letters for each row’s choice, joined by -.

  • The > marks the row the D-pad is on.

  • The D-pad’s right and left offer the next or the last choice in that row, as Blue? A:OK B:Back. Past the end of the row, they go round to the other end.

  • A selects the choice offered. Only then does the first line change.

  • B, up or down clears the offer and goes back to the menu.

  • The D-pad’s down and up move the >. Past the last row, it goes round to the first.

  • At PLAY, the auto asks the menu which alliance and which auto were selected.

This is what the Driver Station shows, after each press:

INIT                    R-N
                        > Alliance: <Red>
                          Auto: <Nothing>
right                   R-N
                        > Alliance: Blue? A:OK B:Back
                          Auto: <Nothing>
B                       R-N
                        > Alliance: <Red>
                          Auto: <Nothing>
right, A                B-N
                        > Alliance: <Blue>
                          Auto: <Nothing>
right, wraps to Red     B-N
                        > Alliance: Red? A:OK B:Back
                          Auto: <Nothing>
down, clears the offer  B-N
                          Alliance: <Blue>
                        > Auto: <Nothing>
left, wraps to the last B-N
                          Alliance: <Blue>
                        > Auto: Forward Then Strafe? A:OK B:Back
A                       B-FS
                          Alliance: <Blue>
                        > Auto: <Forward Then Strafe>
down, wraps to the top  B-FS
                        > Alliance: <Blue>
                          Auto: <Forward Then Strafe>
up, wraps to the bottom B-FS
                          Alliance: <Blue>
                        > Auto: <Forward Then Strafe>
up                      B-FS
                        > Alliance: <Blue>
                          Auto: <Forward Then Strafe>
PLAY                    chosen("Alliance") gives "Blue"
                        chosen("Auto") gives "Forward Then Strafe"

the classes¶

Each class does one job. A class that does one small job is easy to test, and easy to change.

  • L135MenuItem is one choice: a short name, such as F24, and a full name, such as Forward 24.

  • L135MenuRow is one row: its name and its items. It knows which item is selected, and which is offered.

  • L135OptionMenu is the rows, and which row the > is on.

  • L135MenuButtons turns each press of the gamepad into one move of the menu.

  • L135DriverStationMenu is what the OpMode uses. It reads the buttons, then shows the menu on the Driver Station.

An arrow with a diamond means “holds”: an L135OptionMenu holds its L135MenuRows.

One press of the D-pad’s right goes down the classes, one call at a time:

You build it from the bottom up: each class, its tests first, then the class that uses it.

class L135MenuRow {

    String name;
    L135MenuItem[] items;
    int selectedIndex = 0;
    int offeredIndex = 0;

    L135MenuRow(String name, L135MenuItem... items) {
        this.name = name;
        this.items = items;
    }

    String name() {
        return name;
    }

    L135MenuItem selected() {
        L135MenuItem selectedItem = items[selectedIndex];
        return selectedItem;
    }

    String line() {
        L135MenuItem offeredItem = items[offeredIndex];
        String choiceShown = "<" + offeredItem.fullName() + ">";
        if (offeredIndex != selectedIndex) {
            choiceShown = offeredItem.fullName() + "? A:OK B:Back";
        }
        String rowLine = name + ": " + choiceShown;
        return rowLine;
    }
}

    String summary() {
        String summary = "";
        for (int i = 0; i < rows.length; i++) {
            L135MenuItem selectedItem = rows[i].selected();
            if (i > 0) {
                summary = summary + "-";
            }
            summary = summary + selectedItem.shortName();
        }
        return summary;
    }

    String[] lines() {
        String[] lines = new String[rows.length + 1];
        lines[0] = summary();
        for (int i = 0; i < rows.length; i++) {
            String pointer = "  ";
            if (i == pointedRow) {
                pointer = "> ";
            }
            lines[i + 1] = pointer + rows[i].line();
        }
        return lines;
    }

class L135MenuButtons {

    L135OptionMenu optionMenu;

    L135MenuButtons(L135OptionMenu optionMenu) {
        this.optionMenu = optionMenu;
    }

    void loop(Gamepad gamepad) {
        if (gamepad.dpadUpWasPressed()) {
            optionMenu.up();
        }
        if (gamepad.dpadDownWasPressed()) {
            optionMenu.down();
        }
        if (gamepad.dpadLeftWasPressed()) {
            optionMenu.left();
        }
        if (gamepad.dpadRightWasPressed()) {
            optionMenu.right();
        }
        if (gamepad.aWasPressed()) {
            optionMenu.select();
        }
        if (gamepad.bWasPressed()) {
            optionMenu.back();
        }
    }
}

    L135DriverStationMenu(L135OptionMenu optionMenu) {
        this.optionMenu = optionMenu;
        menuButtons = new L135MenuButtons(optionMenu);
    }

    void loop(Gamepad gamepad) {
        menuButtons.loop(gamepad);
        String summary = optionMenu.summary();
        Tracker.publish("menu/summary", summary);
        String[] lines = optionMenu.lines();
        for (int i = 0; i < lines.length; i++) {
            Tracker.printToDs(lines[i]);
        }
    }

    String chosen(String rowName) {
        String fullName = optionMenu.chosen(rowName);
        return fullName;
    }

    void startAt(String rowName, String fullName) {
        optionMenu.startAt(rowName, fullName);
    }

    String summary() {
        String summary = optionMenu.summary();
        return summary;
    }
}

L135S130: run the auto that was selected¶

At PLAY, start() asks the menu which alliance and which auto were selected, and logs both. A switch compares auto with each case and runs the lines under the one that matches, down to its break. The words in each case have to match the item’s full name exactly. Command.NOOP is a command that does nothing. It is what runs for Nothing, which no case matches.

Change. Press Ctrl+C in the Terminal to stop the simulator. In start(), under the comment that names this step, type:

        // When on L135S130, see
        // https://coding.stitt.cc/ftc-lessons-java/guide/tasks/l135.html#l135s130
        // for what to do here.
        String alliance = menu.chosen("Alliance");
        Tracker.publish("menu/alliance", alliance);

        String auto = menu.chosen("Auto");
        Tracker.publish("menu/auto", auto);
        Command chosenAuto = Command.NOOP;
        switch (auto) {
            case "Forward 24":
                chosenAuto = driveForward24();
                break;
            case "Forward Then Strafe":
                chosenAuto = driveForwardThenStrafe();
                break;
        }
        Scheduler.schedule(chosenAuto);
