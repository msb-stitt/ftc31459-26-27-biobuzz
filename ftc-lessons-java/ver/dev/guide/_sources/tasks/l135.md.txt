## the menu, press by press

The menu has two rows. `Alliance` is Red or Blue, and `Auto` is Nothing, Forward 24 or Forward
Then Strafe.

The top line is the **status line**. It holds the short name of the choice selected in each row,
joined by `-`. `R-N` is Red and Nothing. It changes only when A selects a choice.

- The `>` marks the row the D-pad is on.
- Right and left offer the next or the last choice in that row, as `Blue? A:OK B:Back`. Past the
  end of the row, they go round to the other end.
- A selects the choice offered.
- B, up or down clears the offer.
- Down and up move the `>`. Past the last row, it goes round to the first.
- At PLAY, the auto runs the choices selected.

Each picture is one press, and the screen it leaves.

## the classes

Each class does one job. A class with one small job is easy to test, and easy to change. You build
them from the bottom up: `MenuItem`, then `MenuRow`, which holds `MenuItem`s, then `OptionMenu`,
`MenuButtons` and `DriverStationMenu`. For each class, you test it first, then write it.

A class diagram is a box for each class: its name, then its fields, then its methods.

- `-` in front of a name means **private**: only the class's own code can use it.
- `+` means **public**: any code can use it.
- No mark means any class in the same folder can use it.
- `: String` after a method is what it gives back.
- An arrow with a diamond means "holds": a `MenuRow` holds its `MenuItem`s.

A class drawn faint is there to show what holds what. Its own diagram is where you read it.

## MenuItem: one choice

A `MenuItem`'s one job is to hold a choice's two names.

:::{figure} ../_figures/fig-l135-item.png
:name: fig-l135-item
:::

- `shortName` holds the name for the status line, such as `F24`.
- `fullName` holds the name for the row's line, such as `Forward 24`.
- `MenuItem(shortName, fullName)` makes a `MenuItem` from the two names.
- `getShortName()` gives back the short name, and `getFullName()` the full name.

## MenuRow: one row of choices

A `MenuRow`'s one job is to know which of its choices is selected, and which is offered.

:::{figure} ../_figures/fig-l135-row.png
:name: fig-l135-row
:::

- `name` holds the row's name, such as `Alliance`.
- `items` holds the row's `MenuItem`s, in the order they were added.
- `selectedIndex` holds which item is selected, and `offeredIndex` which item the row shows. When
  the two are the same, nothing is offered.
- `MenuRow(name)` makes an empty row, and `add(item)` puts an item at its end.
- `goRight()` and `goLeft()` offer the next or the last item, round the ends.
- `select()` selects the item offered, and `goBack()` clears the offer.
- `getSelected()` gives back the item selected.
- `getLine()` gives back the row's line, such as `Alliance: <Red>` or
  `Alliance: Blue? A:OK B:Back`.

A **sequence diagram** shows calls in time order, from the top down. Each object has a box and a
dashed line down from it. A solid arrow is a call, and a dashed arrow is what the call gives back.
Here `optionMenu` asks `allianceRow` for its line, offers Blue, then selects it:

:::{figure} ../_figures/fig-l135-row-calls.png
:name: fig-l135-row-calls
:::

```{code-block} java
public class MenuRow {

    // 'private' so only this class can use it. 'private' allows access from this class only.
    private String name;
    // 'private' so only this class can use it. 'private' allows access from this class only.
    private ArrayList<MenuItem> items = new ArrayList<>();
    // 'private' so only this class can use it. 'private' allows access from this class only.
    private int selectedIndex = 0;
    // 'private' so only this class can use it. 'private' allows access from this class only.
    private int offeredIndex = 0;

    // 'public' so L140, in another package, can use it. 'public' allows access from any code.
    public MenuRow(String name) {
        this.name = name;
    }

    // 'public' so L140, in another package, can use it. 'public' allows access from any code.
    public void add(MenuItem item) {
        items.add(item);
    }

    // 'public' so L140, in another package, can use it. 'public' allows access from any code.
    public MenuItem getSelected() {
        MenuItem selectedItem = items.get(selectedIndex);
        return selectedItem;
    }

    String getLine() {
        MenuItem offeredItem = items.get(offeredIndex);
        String fullName = offeredItem.getFullName();
        String choiceShown = "<" + fullName + ">";
        if (offeredIndex != selectedIndex) {
            choiceShown = fullName + "? A:OK B:Back";
        }
        String rowLine = name + ": " + choiceShown;
        return rowLine;
    }
}
```

## OptionMenu: the rows together

An `OptionMenu`'s one job is to know which row the `>` is on, and hand each press to that row.
`MenuRow` is drawn faint: you know it already.

:::{figure} ../_figures/fig-l135-option-menu.png
:name: fig-l135-option-menu
:::

- `rows` holds the menu's `MenuRow`s, in the order they were added.
- `pointedIndex` holds which row the `>` is on.
- `add(row)` puts a row at the end of the menu.
- `goUp()` and `goDown()` clear the offer in the row the `>` leaves, then move it, round the ends.
- `goRight()`, `goLeft()`, `select()` and `goBack()` hand the press to the row the `>` is on.
- `getSummary()` gives back the status line, such as `R-N`.
- `getLines()` gives back the status line, then each row's line with `> ` or two spaces in front.

### L135S070: the status line and the lines

In `OptionMenu`, type the `package` line and `import java.util.ArrayList;` above the comment, and
below it:

```{code-block} java
// 'public' so L140, in another package, can use it. 'public' allows access from any code.
public class OptionMenu {

    // 'private' so only this class can use it. 'private' allows access from this class only.
    private ArrayList<MenuRow> rows = new ArrayList<>();
    // 'private' so only this class can use it. 'private' allows access from this class only.
    private int pointedIndex = 0;

    // 'public' so L140, in another package, can use it. 'public' allows access from any code.
    public void add(MenuRow row) {
        rows.add(row);
    }

    String getSummary() {
        String summary = "";
        String between = "";
        for (MenuRow row : rows) {
            MenuItem selectedItem = row.getSelected();
            String shortName = selectedItem.getShortName();
            summary = summary + between + shortName;
            between = "-";
        }
        return summary;
    }

    ArrayList<String> getLines() {
        ArrayList<String> lines = new ArrayList<>();
        String summary = getSummary();
        lines.add(summary);
        MenuRow pointedRow = rows.get(pointedIndex);
        for (MenuRow row : rows) {
            String pointer = "  ";
            if (row == pointedRow) {
                pointer = "> ";
            }
            String rowLine = row.getLine();
            String pointedLine = pointer + rowLine;
            lines.add(pointedLine);
        }
        return lines;
    }
}
```

`between` is empty before the first row, and `-` after it, so `-` goes only between the names.

```{code-block} java
class MenuButtons {

    // 'private' so only this class can use it. 'private' allows access from this class only.
    private OptionMenu optionMenu;

    MenuButtons(OptionMenu optionMenu) {
        this.optionMenu = optionMenu;
    }

    void loop(Gamepad gamepad) {
        if (gamepad.dpadUpWasPressed()) {
            optionMenu.goUp();
        }
        if (gamepad.dpadDownWasPressed()) {
            optionMenu.goDown();
        }
        if (gamepad.dpadLeftWasPressed()) {
            optionMenu.goLeft();
        }
        if (gamepad.dpadRightWasPressed()) {
            optionMenu.goRight();
        }
        if (gamepad.aWasPressed()) {
            optionMenu.select();
        }
        if (gamepad.bWasPressed()) {
            optionMenu.goBack();
        }
    }
}
```

## DriverStationMenu: the menu on the Driver Station

A `DriverStationMenu`'s one job is to be the menu an OpMode uses. Each loop, it reads the buttons.
Then it shows the lines on the Driver Station.

:::{figure} ../_figures/fig-l135-ds-menu.png
:name: fig-l135-ds-menu
:::

- `optionMenu` holds the menu, and `menuButtons` the `MenuButtons` it makes for it.
- `DriverStationMenu(optionMenu)` makes one for the menu.
- `loop(gamepad)` moves the menu for each press, logs the status line as `menu/summary`, and
  prints each line on the Driver Station.
- `getSummary()` gives back the status line.

One `loop()`, from the OpMode's `init_loop()`:

:::{figure} ../_figures/fig-l135-ds-loop.png
:name: fig-l135-ds-loop
:::

### L135S100: put the menu on the Driver Station

The OpMode makes each item, row and menu as a field, and adds them in `init()`.
`OpModeStorage.isRed` is `true` unless an auto run before it chose blue. L140's auto sets it. When
it is `false`, Blue is added first, so Blue is the choice the menu starts at.

**Change.** In `DriverStationMenu`, type the `package` line above the comment, and under it:

```{code-block} java
import com.qualcomm.robotcore.hardware.Gamepad;

import org.firstinspires.ftc.teamcode.base.Tracker;

import java.util.ArrayList;
```

Below the comment, type:

```{code-block} java
// 'public' so L140, in another package, can use it. 'public' allows access from any code.
public class DriverStationMenu {

    // 'private' so only this class can use it. 'private' allows access from this class only.
    private OptionMenu optionMenu;
    // 'private' so only this class can use it. 'private' allows access from this class only.
    private MenuButtons menuButtons;

    // 'public' so L140, in another package, can use it. 'public' allows access from any code.
    public DriverStationMenu(OptionMenu optionMenu) {
        this.optionMenu = optionMenu;
        menuButtons = new MenuButtons(optionMenu);
    }

    // 'public' so L140, in another package, can use it. 'public' allows access from any code.
    public void loop(Gamepad gamepad) {
        menuButtons.loop(gamepad);
        String summary = optionMenu.getSummary();
        Tracker.publish("menu/summary", summary);
        ArrayList<String> lines = optionMenu.getLines();
        for (String line : lines) {
            Tracker.printToDs(line);
        }
    }

    // 'public' so L140, in another package, can use it. 'public' allows access from any code.
    public String getSummary() {
        String summary = optionMenu.getSummary();
        return summary;
    }
}
```
