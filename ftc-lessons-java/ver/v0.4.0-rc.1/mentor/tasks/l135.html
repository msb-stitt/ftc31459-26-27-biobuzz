135 lesson: choose the alliance and the auto¶

After INIT, the Driver Station shows a menu. The driver picks Red or Blue, and L125’s auto or L130’s, with the gamepad’s D-pad, before pressing PLAY.

Before you start.

  • L130 is done.

  • AdvantageScope is installed on the same laptop. No gamepad is needed in the simulator.

  • The robot, the Driver Station, a gamepad, and about 1 m by 2 m of clear floor for the last step.

the steps¶

L135S010: copy the three starters into mytry¶

This lesson has three files. L135Row is one line of the menu: its name, such as Alliance, and its choices, such as Red and Blue. L135AutoMenu holds the rows and reads the buttons. L135ChooseAutoOpMode is the auto.

Copy. In lessons, copy L135Row, L135AutoMenu and L135ChooseAutoOpMode into mytry, one at a time, as in L120.

Check.

  • mytry holds L135Row, L135AutoMenu and L135ChooseAutoOpMode.

L135S020: switch your copy on¶

Change. In L135ChooseAutoOpMode, delete the line @Disabled, under the comment that names this step.

Check.

  • Under the step’s comment, the next line reads // 'public' so the robot can run this OpMode. 'public' allows access from any code.

L135S030: show the menu during INIT¶

Between INIT and PLAY, the robot calls init_loop() again and again. The driver uses that time to choose.

Change. In L135ChooseAutoOpMode’s init_loop(), under the comment that names this step, type:

        // When on L135S030, see
        // https://coding.stitt.cc/ftc-lessons-java/guide/tasks/l135.html#l135s030
        // for what to do here.
        menu.loop(gamepad1);
        initLoopAfter();

menu.loop reads the buttons pressed since the last pass, then prints the menu.

Simulator. In the Terminal, run:

./gradlew :TeamCode:simRun --args="mytry.L135ChooseAutoOpMode --init"

--init keeps the simulator in INIT. The Terminal shows the Driver Station’s lines. Press Enter in the Terminal for PLAY.

Check.

  • The Terminal shows > Alliance: < Red >, then Auto: < F24-Forward 24 >, then R-F24.

The > marks the row the D-pad is on. The last line is the menu in short: R for Red, and F24, the letters before the - in F24-Forward 24.

L135S040: step to the next choice¶

shown holds the choice each row shows, and row is the row the D-pad is on. So shown[row] is the choice the driver is looking at. left() already steps back; right steps forward, and from the last choice goes round to the first.

Change. Press Ctrl+C in the Terminal to stop the simulator. In L135AutoMenu’s right(), under the comment that names this step, type:

        // When on L135S040, see
        // https://coding.stitt.cc/ftc-lessons-java/guide/tasks/l135.html#l135s040
        // for what to do here.
        int lastChoice = rows[row].choices.length - 1;
        shown[row] = shown[row] + 1;
        if (shown[row] > lastChoice) {
            shown[row] = 0;
        }

Simulator. Run it again, with the D-pad’s right pressed:

./gradlew :TeamCode:simRun --args="mytry.L135ChooseAutoOpMode --init --dpad_right=true"

Check.

  • The Terminal shows > Alliance: < Blue >   (A keeps, B puts back).

  • The last line still reads R-F24, because Blue is shown but not kept.

L135S050: keep it, or put it back¶

kept holds the choice each row has kept. A keeps the choice shown. B, or moving to another row, shows the kept choice again.

Change. Stop the simulator. In keep(), under the comment that names this step, type:

        // When on L135S050, see
        // https://coding.stitt.cc/ftc-lessons-java/guide/tasks/l135.html#l135s050
        // for what to do here.
        kept[row] = shown[row];

In putBack(), under its comment, type:

        // When on L135S050, see
        // https://coding.stitt.cc/ftc-lessons-java/guide/tasks/l135.html#l135s050
        // for what to do here.
        shown[row] = kept[row];

Simulator. Run it with right and A pressed:

./gradlew :TeamCode:simRun --args="mytry.L135ChooseAutoOpMode --init --dpad_right=true --a=true"

Check.

  • The Terminal shows > Alliance: < Blue >, with no (A keeps, B puts back).

  • The last line reads B-F24.

L135S060: run the auto that was chosen¶

At PLAY, start() asks the menu which auto was kept. A switch compares auto with each case and runs the lines under the one that matches, down to its break. The words in each case have to match the choice in the menu exactly.

Change. Stop the simulator. In L135ChooseAutoOpMode’s start(), under the comment that names this step, type:

        // When on L135S060, see
        // https://coding.stitt.cc/ftc-lessons-java/guide/tasks/l135.html#l135s060
        // for what to do here.
        switch (auto) {
            case "F24-Forward 24":
                chosenAuto = driveForward24();
                break;
            case "FS-Forward Then Strafe":
                chosenAuto = driveForwardThenStrafe();
                break;
        }

Simulator. Run it with down, right and A pressed, which chooses L130’s auto:

./gradlew :TeamCode:simRun --args="mytry.L135ChooseAutoOpMode --init --dpad_down=true --dpad_right=true --a=true"

AdvantageScope. Connect to the simulator, click 2D Field, and open Localizer, then pinPoint.

Check.

  • The Terminal’s last line reads R-FS.

  • Press Enter in the Terminal. The robot drives forward, then slides to its right, as in L130.

  • x_in reads 96 and y_in 72.

L135S070: turn the field for the blue alliance¶

Each blue place is a red place turned a half-turn about the middle of the field, (72, 72). PoseFactory makes poses. rotateAround gives a PoseFactory that turns each pose it makes. So the autos stay written for red.

Change. Stop the simulator. In poses(), under the comment that names this step, type:

        // When on L135S070, see
        // https://coding.stitt.cc/ftc-lessons-java/guide/tasks/l135.html#l135s070
        // for what to do here.
        String alliance = menu.chosen("Alliance");
        if (alliance.equals("Blue")) {
            chosenPoses = redPoses.rotateAround(72.0, 72.0, 180.0);
        }

equals compares two pieces of text. == does not work for text.

Simulator. Run it with Blue chosen:

./gradlew :TeamCode:simRun --args="mytry.L135ChooseAutoOpMode --init --dpad_right=true --a=true"

Check.

  • The Terminal’s last line reads B-F24.

  • Press Enter. The robot jumps to the top of the field, at x_in 72 and y_in 133.5, facing down, heading_deg 270.

  • It drives 24 inches down the field and stops at y_in 109.5.

L135S080: work the menu on the robot¶

Send. Stop the simulator. Send the code, pick L135 Choose Auto from the autonomous list, and press INIT. Press Start and A on the gamepad, so it is gamepad 1.

Robot. Put the robot on the floor with a piece of tape at its front edge.

Check.

  • The Driver Station shows the menu, with R-F24 last.

  • The D-pad’s down and right, then A, change the last line to R-FS.

  • Press PLAY. The robot drives forward, then slides to its right.

The robot drives the same on the floor for either alliance. Only the numbers on the Driver Station change, because the field is turned, not the robot.

If it didn’t, and LessonsTest.l135_theMenuChoosesTheAllianceAndTheAuto fails with the menu is on the Driver Station during INIT: Live NetworkTables on. AdvantageScope: connect to 192.168.43.1, menu.loop(gamepad1); is missing from init_loop().

If it didn’t, and it fails with right shows Blue, not yet kept: > Alliance: < Red >, right() is empty.

If it didn’t, and it fails with the summary names what was kept: and the line still ends (A keeps, B puts back), keep() is empty.

If it didn’t, and it fails with the robot never started following a path, the switch is missing, or a case’s words differ from the menu’s by a letter or a space.

If it didn’t, and it fails with placed at red's start turned a half-turn expected:<133.5> but was:<10.5>, the if in poses() is missing, or "Blue" is spelled differently.

What you just did. One auto now holds every route, and the drive team picks one during INIT, when the rules let them touch the gamepad. A new route is a new choice in the Auto row and a new case. The routes are written once, for red, and the field is turned for blue.

Where next. L140 uses the same menu to tell the teleop which end of the field the driver stands at.
