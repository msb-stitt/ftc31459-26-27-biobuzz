# 017 how-to: navigate Android Studio's panes

::::{only} mentor
**Before you start.**

- [B010](b010.md) is done: Android Studio has the project open.
::::

:::{admonition} fig-l020-window
:class: pencil
Android Studio's window with the Project tool window on the left, the editor on the right, and the
Terminal below them; the toolbar along the top, the tool window bar down each side, and the status
bar along the bottom.
:::

A video shows every part of this page:
<https://msb-stitt.github.io/ftc31459-26-27-biobuzz/videos/h017.mp4>.

Android Studio's window has these parts:

- **Toolbar**, along the top: runs the code and starts Android tools.
- **Editor**, in the middle: where you read and write the code.
- **Tool windows**, such as Project on the left and Terminal below: each is a pane that does one
  kind of job.
- **Tool window bar**, the buttons down each side: each one opens or closes a tool window.
- **Status bar**, along the bottom: what Android Studio is doing. Its left end is the path to the
  open file. Click a folder in the path to see what it holds.

**Click.**

{.steps}
- Click the folder button at the top of the left side.

- Click it again.

- Click the Terminal button, near the bottom of the left side.

**Check.**

- The first click closes the Project window, and the second opens it again.
- The Terminal opens below the editor, and its button is lit.

**Drag.**

{.steps}
- Drag the edge between Project and the editor to the right.

- Drag the top edge of the Terminal up or down.

**Check.**

- Each name in the Project window shows in full.
- The Terminal grows or shrinks.

**Theme.**

{.steps}
- Click the gear at the top right, then **Theme...**.

- Click **Islands Light**.

**Check.**

- Android Studio turns light. To go back, pick **Islands Dark** the same way.

The pictures in this book use Islands Dark.

**View.**

{.steps}
- Click the name at the top of the Project pane, then **Project**.

- Do it again and pick **Project Source Files**, then again and pick **Android**.

**Check.**

- **Project** shows every file in the project's folder, even the book.
- **Project Source Files** shows only the folders that hold code.
- **Android** shows two parts, **FtcRobotController** and **TeamCode**, and the Gradle scripts.

**Find.**

{.steps}
- In **Project**, open **TeamCode**, then **src**, **main**, **java** and
  **org.firstinspires.ftc.teamcode**.

- In **Android**, open **TeamCode**, then **java** and **org.firstinspires.ftc.teamcode**.

**Check.**

- Each way ends at the same folders, among them **lessons** and **mytry**.

**Sync.**

{.steps}
- Click **File**, then **Sync Project with Gradle Files**.

- Click the **Build** button, the hammer near the bottom of the left side, then the **Sync** tab.

**Check.**

- The **Sync** tab shows a green check by the project's name.

Sync again after you get new code from the internet, so Android Studio sees what changed.

**Target.**

{.steps}
- Click the list just left of the green triangle at the top, then **TeamCode**.

**Check.**

- The list reads **TeamCode**.

**Build.**

{.steps}
- Click the hammer at the top right of the toolbar.

- Click the **Build Output** tab in the **Build** pane.

**Check.**

- The tab shows a green check and `BUILD SUCCESSFUL`.

When the build fails, the mark is red. Open the list under it to find the file, what is wrong, and
the line, as `';' expected :4`.
