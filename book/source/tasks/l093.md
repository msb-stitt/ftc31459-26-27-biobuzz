## the menu, press by press

The menu you try here has three rows. `Light` is On or Off, `Speed` is Slow, Medium or Fast, and
`Color` is Red, Green or Blue. L095 and L135 use the same menu, with rows of their own.

The top line is the **status line**. It holds the short name of the choice selected in each row,
joined by `-`. `ON-S-R` is On, Slow and Red. It changes only when A selects a choice.

- The `>` marks the row the D-pad is on.
- Right and left offer the next or the last choice in that row, as `Off? A:OK B:Back`. Past the
  end of the row, they go round to the other end.
- A selects the choice offered.
- B, up or down clears the offer.
- Down and up move the `>`. Past the last row, it goes round to the first.

Each picture is one press, and the screen it leaves. The first is at the top of this page: at INIT,
each row starts at its first choice, selected, and the `>` is on `Light`.

## the classes

Each class does one job. A class with one small job is easy to test, and easy to change. You build
them from the bottom up: `MenuItem`, then `MenuRow`, which holds `MenuItem`s, then `OptionMenu`,
`MenuButtons` and `DriverStationMenu`. For each class, you test it first, then write it. The tests
use the rows L135's auto uses, `Alliance` and `Auto`.

The class diagrams are drawn as in [E067](e067.md). Two marks are new:

- `-` in front of a name means **private**: only the class's own code can use it.
- A dashed arrow with an open head means "uses": a `MenuButtons` is handed a `Gamepad` each
  loop and asks it about its buttons, but does not hold one.

## MenuItem: one choice

A `MenuItem`'s one job is to hold a choice's two names.

:::{admonition} fig-l093-item
:class: pencil
Stand-in for `fig-l093-item`, made by `book/tools/draw.py`.
:::

- `shortName` holds the name for the status line, such as `F24`.
- `fullName` holds the name for the row's line, such as `Forward 24`.
- `MenuItem(shortName, fullName)` makes a `MenuItem` from the two names.
- `getShortName()` gives back the short name, and `getFullName()` the full name.

### L093S030: one choice, test first

A **test** is code that runs your code and checks what it gives back. `@Test` marks a method JUnit
runs. `assertEquals(expected, actual)` stops the test with a failure when the two differ. You write
the test first, watch it fail, then write the code until it passes.

## MenuRow: one row of choices

A `MenuRow`'s one job is to know which of its choices is selected, and which is offered.

:::{admonition} fig-l093-row
:class: pencil
Stand-in for `fig-l093-row`, made by `book/tools/draw.py`.
:::

- `name` holds the row's name, such as `Alliance`.
- `items` holds the row's `MenuItem`s, in the order they were added.
- `selectedIndex` holds which item is selected, and `offeredIndex` which item the row shows. When
  the two are the same, nothing is offered.
- `MenuRow(name)` makes an empty row, and `add(item)` puts an item at its end.
- `goRight()` and `goLeft()` offer the next or the last item, round the ends.
- `select()` selects the item offered, and `goBack()` clears the offer.
- `getSelected()` gives back the item selected.
- `getLine()` gives back the row's line, such as `Alliance: <Red>` or
  `Alliance: Blue? A:OK B:Back`.

A **sequence diagram** shows calls in time order, from the top down. Each object has a box and a
dashed line down from it. A solid arrow is a call, and a dashed arrow is what the call gives back.
Here `optionMenu` asks `allianceRow` for its line, offers Blue, then selects it:

### L093S040: one row, and its line

An `ArrayList` holds a list of objects, and grows as you add to them. `ArrayList<MenuItem>` is a
list of `MenuItem`s. It starts empty. `add(item)` puts `item` at its end, `get(i)` gives back the
item at `i`, counting from 0, and `size()` is how many it holds. `import java.util.ArrayList;`
lets the class use it.

public class MenuRow {

    // 'private' so only this class can use it. 'private' allows access from this class only.
    private String name;
    // 'private' so only this class can use it. 'private' allows access from this class only.
    private ArrayList<MenuItem> items = new ArrayList<>();
    // 'private' so only this class can use it. 'private' allows access from this class only.
    private int selectedIndex = 0;
    // 'private' so only this class can use it. 'private' allows access from this class only.
    private int offeredIndex = 0;

    // 'public' so later lessons, in other packages, can use it. 'public' allows access from any code.
    public MenuRow(String name) {
        this.name = name;
    }

    // 'public' so later lessons, in other packages, can use it. 'public' allows access from any code.
    public void add(MenuItem item) {
        items.add(item);
    }

    // 'public' so later lessons, in other packages, can use it. 'public' allows access from any code.
    public MenuItem getSelected() {
        MenuItem selectedItem = items.get(selectedIndex);
        return selectedItem;
    }

    String getLine() {
        MenuItem offeredItem = items.get(offeredIndex);
        String fullName = offeredItem.getFullName();
        String choiceShown = "<" + fullName + ">";
        if (offeredIndex != selectedIndex) {
            choiceShown = fullName + "? A:OK B:Back";
        }
        String rowLine = name + ": " + choiceShown;
        return rowLine;
    }
}

## OptionMenu: the rows together

An `OptionMenu`'s one job is to know which row the `>` is on, and hand each press to that row.
The diagram shows `MenuRow` and `MenuItem` too, since the calls below reach them. `MenuItem` is
drawn as only its name; its own diagram is above.

`row` holding that row. It is a for-each loop, and it needs no `i`. `==` on two objects asks

```{code-block} java
:caption: mytry/l093/OptionMenu.java
// 'public' so later lessons, in other packages, can use it. 'public' allows access from any code.
public class OptionMenu {

    // 'private' so only this class can use it. 'private' allows access from this class only.
    private ArrayList<MenuRow> rows = new ArrayList<>();
    // 'private' so only this class can use it. 'private' allows access from this class only.
    private int pointedIndex = 0;

    // 'public' so later lessons, in other packages, can use it. 'public' allows access from any code.
    public void add(MenuRow row) {
        rows.add(row);
    }

    String getSummary() {
        String summary = "";
        String between = "";
        for (MenuRow row : rows) {
            MenuItem selectedItem = row.getSelected();
            String shortName = selectedItem.getShortName();
            summary = summary + between + shortName;
            between = "-";
        }
        return summary;
    }

    ArrayList<String> getLines() {
        ArrayList<String> lines = new ArrayList<>();
        String summary = getSummary();
        lines.add(summary);
        MenuRow pointedRow = rows.get(pointedIndex);
        for (MenuRow row : rows) {
            String pointer = "  ";
            if (row == pointedRow) {
                pointer = "> ";
            }
            String rowLine = row.getLine();
            String pointedLine = pointer + rowLine;
            lines.add(pointedLine);
        }
        return lines;
    }
}
```

`between` is empty before the first row, and `-` after it, so `-` goes only between the names.

class MenuButtons {

    }

public class DriverStationMenu {

    // 'private' so only this class can use it. 'private' allows access from this class only.
    private OptionMenu optionMenu;
    // 'private' so only this class can use it. 'private' allows access from this class only.

        }
