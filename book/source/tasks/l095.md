# 095 lesson: choose the shaping from a menu

:::{admonition} fig-l095-press-01
:class: pencil
Stand-in for `fig-l095-press-01`, made by `book/tools/draw.py`.
:::

After INIT, the menu you wrote in L093 picks how the sticks are shaped: how big the deadband is,
and linear, squared or cubed. Then you drive, and find the one you like best.

::::{only} mentor
**Before you start.**

- L090 and L093 are done, so `mytry` holds L065's `StickShaper` in `mytry/l065` and L093's menu in
  `mytry/l093`.
- AdvantageScope is installed on the same laptop, and a gamepad is plugged into the laptop.
- No robot is needed.
::::

## the menu

The menu has two rows.

- `Band` is the deadband: 0.05, 0.00, 0.025, 0.075 or 0.10. A stick pushed less than the band
  counts as centred.
- `Shape` is Squared, Linear or Cubed. Linear passes the stick on as it is. Squared and Cubed make
  a small push smaller, so the robot creeps.

A row starts at the first choice added to it. So each row's first choice is the setting the
later lessons use: a band of 0.05, and Squared. The status line, `0.05-S`, says so.

### L095S040: hand the choices to the StickShaper

At PLAY, the OpMode asks each row which choice is selected, and sets the `StickShaper` to match.
`getSelected()` gives back the very `MenuItem` you made, so `==` tells which one it is, as in L093.

**Change.** In `start()`, under the comment that names this step, type:

```{code-block} java
:caption: mytry/L095ShapingMenuOpMode.java
:emphasize-lines: 4-32

        // When on L095S040, see
        // https://coding.stitt.cc/ftc-lessons-java/guide/tasks/l095.html#l095s040
        // for what to do here.
        MenuItem band = bandRow.getSelected();
        Tracker.publish("menu/band", band.getFullName());
        if (band == band000) {
            stickShaper.setBand(0.00);
        }
        if (band == band0025) {
            stickShaper.setBand(0.025);
        }
        if (band == band005) {
            stickShaper.setBand(0.05);
        }
        if (band == band0075) {
            stickShaper.setBand(0.075);
        }
        if (band == band010) {
            stickShaper.setBand(0.10);
        }

        MenuItem shape = shapeRow.getSelected();
        Tracker.publish("menu/shape", shape.getFullName());
        if (shape == linear) {
            stickShaper.setShape(StickShaper.Shape.LINEAR);
        }
        if (shape == squared) {
            stickShaper.setShape(StickShaper.Shape.SQUARED);
        }
        if (shape == cubed) {
            stickShaper.setShape(StickShaper.Shape.CUBED);
        }
```

`driveFromTheSticks()` does not change. It still calls `stickShaper.shaped`, and gets back
whatever the menu chose.

**Simulator.** Run the same command again.

**AdvantageScope.** Connect to the simulator as in L020, and click **2D Field**. Open the
`drivetrain` folder.

**Check.**

- Press Enter in the Terminal for PLAY, with no presses. Push the left stick halfway forward.
  `forwardXSpeed` reads 0.25: a band of 0.05, and Squared.
- Stop, and run it again. This time choose 0.10 and Linear, as in L095S030, then press Enter.
  Halfway forward reads 0.5, and a tiny push reads 0.

### L095S050: find the settings you like

**Simulator.** Run the same command again for each setting you want to try. Choose it, press
Enter, and drive the robot around the field. Try to stop it on a spot, and to turn it slowly.

**Check.**

- Write down the band and the shape you liked best, and why.

Later lessons go back to a band of 0.05 and Squared. On your own robot, you can choose what you
like.

::::{only} mentor
**No gamepad.** Control options stand in for the presses during INIT, held from the first pass:
`--args="mytry.L095ShapingMenuOpMode --init --dpad_left=true"` offers 0.10. After PLAY,
`--left_stick_y=-0.5` holds the stick halfway forward, with the first choices.

**Our tests.** `LessonsTest`'s L095 tests choose with the gamepad during INIT, then drive:
`./gradlew :TeamCode:testDebugUnitTest --tests '*LessonsTest.l095*'`.

**If it didn't**, and a tiny push still moves the robot with 0.10 chosen, an `if` in L095S040 is
missing, or names the wrong item. `LessonsTest.l095_theMenuChoosesTheBandAndTheShape` fails with
`inside the chosen band: front left expected:<0.0> but was:<0.07999999821186066>`.

**What you just did.** The menu sets the `StickShaper`, and the code that drives only calls
`shaped`. It does not know a menu exists. A new shape would change `StickShaper` and the menu, and
nothing that drives.
