# Figures, taken and not taken

**Status: controlling.** The register every figure in the guide is listed in.

A figure that does not exist yet is **pencilled**: the page shows a visible box carrying the
figure's id and what makes it, so a reader can see the guide is unfinished there and a writer can
keep going. What the picture must show is its row here, and the build puts that under the box's
words, so it is written only here. The release build puts the picture in the box's place, with no
caption. `tools/check_figures.py` checks both directions, and it is the only place the number of
pencilled figures is counted.

A figure no page shows is **unused**: its row stays with `unused` as its status, and `draw.py`
keeps what draws it. Its drawing is committed to `corbels-lfs-lessons` like any other, so a full
draw run leaves nothing to commit. To bring it back, put its box in a page and its status back to
`pencilled`.

How to add one: put the box in the page and the row here, in the same commit.

How to take a screenshot of Android Studio: run `ftc-claude`'s `tools/figures/prep.sh` first, as
`tools/figures/prep.sh l120 L120CompareLocalizersOpMode solutions-minor-fixes`, and look at the
`scratch/figures/prep.png` it writes. It closes every editor tab, fills `mytry` with every earlier
lesson's answer and the lesson's fresh copies, and opens the copy named, so no earlier lesson's tab
is open and none is underlined in red. It moves whatever `mytry` held to `scratch/mytry-saved-TIME`
first. The copies are not added to git, so the project pane shows their names in git's color for a
new file.
